# Admin Dashboard

A modern and responsive admin dashboard built with **Next.js, TypeScript, Tailwind CSS, and shadcn/ui**.

The project focuses on creating a clean dashboard experience with reusable UI components, responsive layouts, and a scalable frontend structure.

## ✨ Features

- 📊 Modern admin dashboard interface
- 📱 Fully responsive design
- 🎨 Clean and reusable UI components
- 🧩 Built with shadcn/ui
- 🌙 Dark and light theme support
- 📈 Dashboard data visualization
- 👥 User management interface
- ⚡ Fast and optimized Next.js application
- 🧱 Component-based architecture

## 🛠️ Tech Stack

### Frontend

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui

### Tools

- Git
- GitHub
- ESLint
